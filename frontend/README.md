# CornAgent Frontend

状态：active

基于 React 和 Vite 的 Agent 界面。`src/agent` 提供独立聊天页与侧边栏面板，包含会话状态、SSE、Markdown、执行过程、子任务状态与摘要、问题卡及文件输入。

```sh
npm ci
npm run dev
```

默认 http://127.0.0.1:5173，API 同源代理至 8000。`/chat` 空白对话、`/chat/:id` 历史详情、`/sidebar` 侧边栏范例、`/rendering` Agent 渲染效果。

开发监听地址和端口读取根目录 `.env` 的 `CORNAGENT_FRONTEND_HOST` / `CORNAGENT_FRONTEND_PORT`，API 代理跟随 `CORNAGENT_SERVER_HOST` / `CORNAGENT_SERVER_PORT`。只在 Vite 服务端读取；不会把根目录中的模型、数据库或存储密钥注入前端代码。修改配置后重启 Vite。

```sh
npm run lint
npm test
npm run build
```

构建后 FastAPI 可以同源托管 `dist`，无需额外 BFF。

从左侧“Agent 渲染效果”进入 `/rendering` 可反复测试 `MarkdownMessageContent`。演示区只展示 Agent 消息内容及测试控制按钮，复用正式消息渲染器，支持思考、工具标题流光、工具组、流式正文、边界切换、停止/重置、390px 窄栏与主题/语言切换。`src/previews/messagePreviewScript.ts` 定义演示阶段：工具运行标题保持数秒后切换为完成态，后置工具留在正文下方，新正文到达时触发收起。所有内容均为合成数据，不调用模型或修改会话。页面使用应用共享导航和 Provider，随前端一起构建，可直接访问和刷新。

工具标题、工具组标题与思考标题统一使用 `src/components/ShimmerText.tsx`。组件采用双层文字：底层保持可读，高亮层以 2000ms 周期扫过，颜色跟随主题；标题或语言更新时同步高亮文字，完成或失败后停止。装饰层对辅助技术隐藏，减少动态效果模式停用动画。可通过 `--shimmer-dur`、`--shimmer-base`、`--shimmer-highlight`、`--shimmer-band` 和 `--shimmer-ease` 调整效果。

工具和工具组的标题变更共用 `src/components/TextSwap.tsx`：旧标题用 150ms 上移 4px、模糊 2px 并淡出，新标题随后从下方进入。组件通过 Motion 的顺序退出机制保留旧帧、合并连续更新，避免手动改 DOM 或强制重排；标题流光跟随显示帧，读屏名称立即更新为最新标题，减少动态效果模式直接替换文字。组件按标题属性记忆渲染结果，流式正文更新不触发相同标题的重复渲染；可通过 `durationMs` 调整每段时长。

渲染页的“首 token 演示”及完整流程从无图标的“正在思考”开始。首次收到有效思考、正文或工具内容后，同一个过程标题用 50ms 退出、50ms 进入切换为“已处理”；空白占位不触发。分隔线随后从左向右以 `scaleX` 展开，耗时数字独立更新，不重播标题动画。只有正文存在且过程区有内容时才允许折叠，过程按钮不使用点击缩放。聊天页与侧栏复用该逻辑，历史消息直接显示已处理状态；减少动态效果模式立即切换。静态演示阶段保留内容引用，避免定时器重复提交相同渲染帧。

## 导航与主题

主侧栏标题左侧使用 [CornAgent SVG 图标](../assets/brand/cornagent.svg)，通过 CSS mask 跟随主题文字色，图标与名称垂直居中。左侧菜单底部居中显示 `Made by xiaotongyu.com`，位于导航滚动区之外，随菜单折叠或打开；点击或用键盘激活署名时，`sidebar/SidebarCredit.tsx` 根据按钮的实时位置发射 canvas-confetti。烟花遵守系统减少动态效果偏好，署名不触发页面跳转或会话操作。

应用通用图标统一使用 `lucide-react`，包括导航、聊天工具栏、历史选择器、搜索弹窗与 Agent 面板；新增图标直接使用该库，不引入其他图标库。导航和工具栏图标为 16px、描边为 1.75，选中勾号使用 2.5 描边。侧栏包含首页、侧边栏示例、Agent 渲染效果和可折叠的聊天分组，可点击导航项统一为 32px。支持新建对话、历史分页、宽度调整与折叠预览。语言、主题、侧栏宽度及折叠状态保存在当前浏览器。首次使用跟随系统深浅主题，手动切换后使用保存的选择；CSS 与 Ant Design 共享黑白主色。窄屏使用抽屉导航，支持遮罩关闭、Escape 和键盘焦点管理。`/sidebar` 为 Agent 面板集成示例，页面标题为“在您的业务页面，询问AI”，下方复用 Ant Design Skeleton 组合博客文章布局；顶部“询问AI”按钮打开面板。

已保存会话的删除入口位于聊天详情右上角和侧栏会话菜单，复用确认弹窗与工作区删除方法。删除当前会话后回到 `/chat`；删除其他会话时保留当前页面。空白新对话在首次发送前没有 Session，不显示会话删除入口。

共享确认弹窗沿用 Ant Design 的主题面板、统一内边距和按钮布局。`Modal.confirm` 的 `body` 语义仅指描述区，不用于包裹标题和页脚；不要为描述区单独设置卡片背景。危险操作使用 `color="danger"` 与 `variant="solid"`，避免 LobeHub 对旧式主按钮文字的黑白主题覆盖；危险按钮文字保持白色，弹窗默认聚焦取消按钮。

`src/App.tsx` 负责路由与工作区组合；主导航在 `src/components/sidebar`，Agent 对话与面板在 `src/agent`。复用同一工作区 hook 和 gateway，避免为页面、侧栏分别维护会话状态。

公共接入入口为 `src/agent/index.ts`，提供 `CornAgentProvider`、`AgentLauncher`、`AgentSidebar` 与 `useAgent`。最小示例、API 配置和组件职责见 [前端接入](../docs/frontend-integration.md)。

## 多语言开发

界面支持简体中文与英文。新增文案集中放入 `src/i18n/catalog.ts`，通过 `useI18n().t(key, params)` 读取；键名有类型检查，动态文件名、数量等使用命名占位符。已有组件的双语 `text` 接口仍可使用。

语言切换同步更新文档语言、日期库及组件库语言。仅翻译界面文案与应用生成的状态提示；会话标题、用户输入、模型回复、问题选项和文件名保留原文。运行时诊断与过程标题在 `src/i18n/systemMessages.ts` 的展示边界转换，不修改持久化数据或 SSE 协议。

语言和主题变化不应重建工作区或订阅 SSE，也不应清空消息草稿、附件与提问回答。组件测试覆盖导航、键盘调整宽度、输入草稿和提问回答在语言切换时的保留；修改这些行为后执行上述检查。

样式使用组件类名，不依赖翻译后的 `aria-label`。`.sr-only` 等共享辅助样式放在基础样式层，避免组件依赖其他页面的 CSS。附件文档卡片高度由内容决定，图片保持 `1:1` 预览；混合附件顶部对齐，托盘为悬浮操作按钮预留内边距。

## 消息编辑与分支

聊天页和侧栏共用 `AgentMessageList`：按用户消息与对应回答分组，最新一轮至少占满输入区上方的可视高度。同一会话发送或编辑成新一轮时，以 360 毫秒 cubic-out 缓动滚动定位到该轮；流式更新不打断过渡，滚轮、触摸及键盘滚动可随时接管。首次打开或切换会话直接定位，遵守系统“减少动态效果”偏好。回复超出一屏后按阅读位置跟随，上滚历史会暂停自动跟随。加载更早消息保留阅读位置，容器高度变化由 `useConversationScroll` 统一处理。

“已处理”过程区只有在后方存在非空正文时才允许折叠；仅含过程或空白正文时始终展开，结束、失败或刷新恢复不会把唯一可见内容收起。

正文边界移动时，`AnimatedMessageBody` 的 boundary 预设保留退出前的内容快照，在约 440 毫秒内将旧正文与已展开的过程区平滑收起：内容轻微上移，裁切边缘从左侧先向上推进到右侧，容器高度同步归零。工具与思考内容的 accordion 预设使用对称的 250 毫秒 smooth-out 展开和收起，不执行正文边界裁切。退出节点立即停止接收交互，重新展开可中断退场；系统减少动态效果时直接切换。流式正文增长不重新启动退场动画。禁用折叠标题保持与普通标题一致的颜色、透明度，仅禁止展开交互。
折叠边界为最后一个非空正文块的起点：只收起此前内容，该正文及后续工具组、子任务和思考按原顺序显示在外部；新正文块出现后才前移边界。空白流式占位不改变边界，待回答问题始终保持可操作。历史快照与流式更新复用同一投影函数。

用户气泡下方预留操作栏，悬停或键盘聚焦时显示复制、编辑按钮，触屏直接显示。编辑器使用无内边框的单行 Input，与右侧取消、保存按钮同行；支持 Enter 或 `Ctrl/Cmd + Enter` 提交；请求失败保留草稿。编辑只提交正文，附件沿用原消息。

编辑通过工作区 `edit(messageId, content)` 创建消息树的新分支，并订阅新回答的 SSE；原消息及其后续对话保持完整。用户消息和 AI 回答复用版本控件，用户版本切换放在复制、编辑按钮组右侧，切换后恢复目标分支的后续对话，选择持久化到服务端。运行中禁用编辑、重新生成及分支切换。

`chat/MessageActions.tsx` 统一复制按钮、图标按钮与版本切换；`chat/UserMessage.tsx` 管理编辑草稿；`chat/useMessageAction.ts` 统一操作失败提示和重复提交保护。完整页与侧栏直接复用这些组件。

聊天输入组件统一使用 14px 文字。聚焦边框使用独立的蓝色 `--composer-focus`，不跟随黑白主按钮颜色。`AgentConversation` 在当前会话生成结束、输入框恢复可用后自动聚焦一次，连续发送无需再次点击输入框；聊天页与侧栏共用该行为。聚焦使用 `preventScroll`，不会打断会话滚动；等待操作完成后再执行，切换会话时清除上一会话的待聚焦状态。

AI 回复完成且正文包含 🎉 时，调用 `agentCelebration.ts` 播放庆祝动画。效果采用 canvas-confetti 的 [Realistic Look](https://www.kirilv.com/canvas-confetti/#realistic)，从左右边缘同时朝中上方喷射，每侧 200 个粒子分为五组，混合扩散角度、初速度、阻力与大小；遵守系统减少动态效果偏好。

## 子任务投影

子任务复用 `tool_call`，通过 `SubagentTaskMetadata` 与稳定部件标识整体更新；`waiting_for_subagents` 仍是可停止的活跃 Run。聊天页与侧边栏共用任务分组、标题、可展开摘要和配色组件；不显示子任务状态徽标与详情行；模拟搜索标题明确标记模拟数据。只翻译状态与标签，保留模型任务标题和结果原文。历史与 SSE 共用相同快照，无独立 Child 聊天接口；协议与演示见 [子任务说明](../docs/subagents.md)。
